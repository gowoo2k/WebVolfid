# WebVolfid

볼피드 도스용을 웹에서 도스박스 없이 바로 플레이 가능하게 포팅한 버전입니다
원작과 100% 동일하지만 않지만 대부분을 구현했습니다.

• 원작권자: TAITO Corporation (타이토)
	• 볼피드는 원래 타이토가 1989년에 아케이드(오락실)용으로 개발 및 출시한 SF 스타일의 땅따먹기(Qix 후속작) 게임입니다.
• DOS 버전에 대한 저작권:
	• 개발/이식: Oxford Digital Enterprises (ODE) 또는 Empire Interactive가 이식 작업을 담당했습니다.
	• 퍼블리셔 (배급사): Empire Software (Empire Interactive)

게임 데이터와 모든 권리는 저작권자에게 있습니다.
